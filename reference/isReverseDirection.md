# This function predicts if the edge diractions are wrong based on graphical position of the KEGG nodes

This function predicts if the edge diractions are wrong based on
graphical position of the KEGG nodes

## Usage

``` r
isReverseDirection(snode, tnode, g)
```

## Arguments

- snode:

  parent node id

- tnode:

  child node id

- g:

  a graphNEL graph

## Value

TRUE or FALSE
