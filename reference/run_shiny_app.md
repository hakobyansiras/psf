# Run KEGG interactive editor and visualization App

Run KEGG interactive editor and visualization App

## Usage

``` r
run_shiny_app(port = 3838)
```

## Arguments

- port:

  The TCP port that the application should listen on. Default value is
  3838

## Value

Nothing is returned

## Examples

``` r
if (FALSE) { # \dontrun{
    runShinyApp()
} # }
```
