# Import edge weights extracted(further edited) via edge_data_frame_from_graph function

Import edge weights extracted(further edited) via
edge_data_frame_from_graph function

## Usage

``` r
update_edge_weights(edge_weights, g)
```

## Arguments

- edge_weights:

  vector with edge weigths with the order of edge_table generated by
  edge_data_frame_from_graph function

- g:

  graphNEL graph which will be updated
