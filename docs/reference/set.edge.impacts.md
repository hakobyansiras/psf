# Sets edge impacts for PSF analysis

Sets edge impacts for PSF analysis

## Usage

``` r
set.edge.impacts(
  g,
  subtype1.attr = "subtype1",
  subtype2.attr = "subtype2",
  impact.attr.name = "impact"
)
```

## Arguments

- g:

  GraphNEL object

- subtype1.attr:

  attribut name for subtype1

- subtype2.attr:

  attribute name for subtype2

- impact.attr.name:

  name of impact attribut
